# `src/deflate/` — the pure-JS DEFLATE codec

Cross-cutting rules — the protocol revision, no runtime dependencies, commands, the package layout — are in the root `CLAUDE.md`; the layering of `src/` and the hot-path conventions are in `src/CLAUDE.md`. A rule lives in ONE file: add to the file of the folder it is about.

`src/deflate/` — the pure-JS DEFLATE codec behind the `@alexify/wrpc/deflate` subpath (browser-reachable, its own budget, deliberately outside every other entry): `inflate.js` (RFC 1951 complete — stored/fixed/dynamic, table-driven, a preset dictionary preloading the output window, `maxOutput` cap, coded `DeflateError`s), `deflate.js` (LZ77 over hash chains against the dictionary, ONE fixed-Huffman block, stored fallback — fixed codes match dynamic on small messages, `bench/deflate-js.js`), `index.js` (`createDeflateCodec`: the `Compressor`, id shared with `dictionaryCompressor` for the same bytes, the `nativeAbove` hand-off to CompressionStream in a browser). Tests in `tests/deflate/` are an interop matrix against zlib and the platform streams plus a fuzz corpus — the codec is the smaller half.
