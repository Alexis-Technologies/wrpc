# `src/websocket/` — the built-in WebSocket engine

Cross-cutting rules — the protocol revision, no runtime dependencies, commands, the package layout — are in the root `CLAUDE.md`; the layering of `src/` and the hot-path conventions are in `src/CLAUDE.md`. A rule lives in ONE file: add to the file of the folder it is about.

`src/websocket/` — a from-scratch WebSocket server implementation (handshake, framing, `WebsocketServer`, `Connection`, `SegmentQueue` O(n) receive buffering in `segments.js`, RFC 7692 permessage-deflate in `permessage-deflate.js`) used by `src/transport.js`; Node-only, never bundled for the browser. Published as the `@alexify/wrpc/ws` subpath (`src/websocket/ws.js`, with the hand-maintained `src/websocket/ws.d.ts` beside it) — engine internals are NOT exported from the main barrel. `WebsocketServer`'s `server` option is optional: without it nothing is bound and upgrades are driven by hand through the public `handleUpgrade(req, socket, head)`, which is how middleware adapters hook a listener they do not own.

`upgrade.js` is the leaf both engines read an upgrade request with: `getPathname`, `negotiateProtocol` and `gateVerdict` in `src/websocket/upgrade.js` (the uWebSockets.js adapter and `src/adapters/common.js` require it — never a second copy). A `verifyClient` gate admits with `true` alone: `gateVerdict` refuses a promise and says so once (`ws.gate.async`).

What a peer can make a `Connection` hold is bounded in three places, each by what it costs: the inflate inbox (`INBOX_HIGH` in `src/websocket/connection.js` — every message that waits behind an asynchronous inflate is counted, compressed or not, and the frame loop stops at the mark), the outbound ordering queue (a `Deque`, created only under context takeover or `async`; `bench/ws-outbox.js`), and the loop turn itself: `TURN_BUDGET` in `src/websocket/connection.js` (512 messages or 256 KiB delivered, then the socket waits for `setImmediate`; `bench/ws-fairness.js`). `turnBudget` is ON for the connections `WebsocketServer` creates and OFF on a bare `Connection`, like `coalesce`. A refused upgrade is one `ws.refused` line (`#refuse` in `src/websocket/server.js`).

`src/websocket/frame-parser.js` keeps RFC 6455's short names (`len`, `buf`, the mask key) where it transcribes the framing — the full-word rule of `js-conventions` gives way to the RFC the parser is checked against.
