# `src/client/` — the RPC client

Cross-cutting rules — the protocol revision, no runtime dependencies, commands, the package layout — are in the root `CLAUDE.md`; the layering of `src/` and the hot-path conventions are in `src/CLAUDE.md`. A rule lives in ONE file: add to the file of the folder it is about.

`src/client.js` (barrel) + `src/client/` — `WrpcClient`/`WrpcClientProxy`: the RPC client (WS/HTTP/worker-event transports — the `event` one takes `worker` as a ServiceWorker, a SharedWorker (reached through its `port`), a dedicated Worker or a raw MessagePort, and `WrpcClientProxy` on the worker side listens on both `self` `message` and the SharedWorker `connect` event, call scaffolding via `#scaffold`, reconnect with exponential backoff + full jitter, app-level `ping`/`pong` heartbeat, automatic re-`load()` of loaded units on `'reconnect'`), plus `connect` — a one-line alias of `WrpcClient.connect` that exists so the contract type has a natural home (`connect<Api>(url)`). The `authenticate` hook is awaited inside `open()` and again on every reconnect BEFORE `#restore` re-sends its subscribe packets (the window an `'open'` listener cannot reach); `refresh` is a single-flight one-shot-retry credential refresh; `client.call(target, args, options)` is the unscaffolded escape hatch those hooks use; the `headers`/`meta` options are connection-phase declarations re-resolved per open — real headers on http/sse AND on ws from Node (`src/client/wsHandshake.js`: the built-in undici WebSocket takes `{ protocols, headers }`; a constructor that throws on the init bag falls back to the browser half), `wrpc.h.<b64u>`/`wrpc.m.<b64u>` subprotocol carrier tokens on ws from a browser (`wsHandshake.browser.js` — a page can set NO handshake header but `Sec-WebSocket-Protocol`; verified by PoC, and `ws`/socket.io cannot either), ONE 2048-byte budget for both tokens, the Bearer lift `wrpc.bearer.<token>` outside it, and the `wrpc_h`/`wrpc_meta` query only by `carrier: 'query'`, under an empty `protocols` offer (a token needs a protocol the server can echo), or on WebTransport.

Hooks are held to the connect deadline: `#within` in `src/client/core.js` races `authenticate`, `headers()`/`meta()` and `refresh` against `connectTimeout`. A timeout option is checked once, by `timeoutOf` in `src/client/core.js` (a number in 1..2^31-1, else a `TypeError`), and a call that timed out here is cancelled there (`#cancel` in `src/client/core.js` sends the `cancel` packet and remembers the id, `MAX_CANCELLED` of them, so a late answer is not an error). A unit object is an `Emitter`, and a procedure may be named like one of its members: the client reads events through `Emitter.prototype`, never through the unit. Behind a worker, `#track` and `#forward` in `src/client/proxy.js` route every packet of a page — events without an id and batches included.
