# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately via
[GitHub Security Advisories](https://github.com/Alexis-Technologies/wrpc/security/advisories/new)
or by emailing the author (see `package.json`). Do not open public issues for
security reports. You should receive a response within a few days.

## Supported versions

Only the latest published release receives security fixes. The package has
not been published to npm yet.
